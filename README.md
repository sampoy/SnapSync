# SnapSync.pro

SnapSync 是一款 macOS 文件同步与项目备份工具。支持批量 ZIP 备份、基于 rsync 的增量同步和镜像同步，以及阿里云 OSS 和腾讯云 COS 上传。

- [下载 v2.3 测试版与校验文件](https://github.com/sampoy/SnapSync/releases/tag/v2.3)
- [官网与使用说明](https://snapsync.pro/)
- [所有版本](https://github.com/sampoy/SnapSync/releases)
- [提交问题或建议](https://github.com/sampoy/SnapSync/issues)

v2.3 测试版要求 macOS 26.3 或更高版本，支持 Apple 芯片与 Intel Mac。
